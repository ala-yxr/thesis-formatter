使用说明与注意事项
  • 隐私安全：所有处理都在你的浏览器本地完成，文件不会上传到任何服务器。
  • 学科选择：进入工具时先选择「工科论文 / 文科论文」，进入后顶栏显示当前学科，点击「切换」可随时改选。工科与文科的设置、学校预设、自定义学校完全隔离——在文科模式下的任何修改都不会影响工科格式。
  • 学校要求：设置面板顶部的下拉框只显示当前学科下的学校格式预设（工科如重庆工程学院《附件8》），选择后自动切换全部格式要求；点击「＋ 添加学校要求」可上传该校的要求文档，保存当前格式设置为该校预设（下次直接切换，且只出现在当前学科的下拉中），也可删除自定义预设。
  • 格式依据：重庆工程学院预设按《附件8 本科毕业设计（论文）撰写格式要求》：页边距 2.5cm、行距固定 20 磅、一级三号黑体居中、二级小三号黑体居左、三级四号黑体居左右缩两字、图题表题五号宋体、参考文献五号宋体序号左顶格、三线表、一级标题换页、前置罗马数字页码等。
  • 封面保留：「摘要」之前的页面（封面、声明、任务书等）保持原样不动，避免破坏学校模板。
  • 目录：自动识别目录页（「目录/目次」标题、Word 目录样式 TOC、超链接条目、点线页码等特征），条目按小四宋体、2-4 级、下级右缩两字重排；生成的是 Word 自动目录域，打开文档时会自动更新页码（Word 可能提示「是否更新域」，选「是」）。若想手动刷新：右键目录 →「更新域」→「更新整个目录」。
  • 公式：公式原样保留（不会改动字号），预览中可能显示不完整，以 Word 为准。
  • 表格：默认按三线表处理——清除表级边框与每行自带的行级边框（w:tblPrEx），保留顶线/底线两根 1.5 磅线，表头行加 0.75 磅栏目线，并让每行不跨页断裂（可关闭）；图片全部原样保留。
  • 图片：所有含图片的段落自动改为单倍行距，避免固定行距把图片截断显示不全。
  • 页码：若原文档已有页码则保留数字样式；封面（首页）不显示页码；分节页码功能让摘要/目录用罗马数字、正文从绪论起用阿拉伯数字从 1 重新编号（与附件8一致，可关闭）。
  • 页眉：正文起各分节的页眉自动改为「当前页所在章的一级标题」（五号宋体居中 + 下划线，用 Word 的 STYLEREF 域实现，改章名后页眉自动跟随）；封面、摘要、目录等前置部分的页眉保持原样不动。页眉/页脚距离已按 1.6cm / 2.1cm 设置。
  • 结构识别：按「摘要 → 关键词 → Abstract → Keywords → 目录 → 章节 → 参考文献 → 致谢/附录」自动识别，个别特殊版式可能需要手工微调。
